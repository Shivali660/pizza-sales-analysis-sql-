# Pizza Sales Analysis Using SQL

## Project Overview
This project focuses on analysing pizza sales data using SQL to understand sales performance, customer ordering patterns, and revenue trends. The analysis covers basic, intermediate, and advanced SQL queries.

## Tools Used
- SQL
- MySQL
- Relational database with four tables

## Key Analysis Performed

### 1. Basic Analysis
- Retrieved the total number of orders placed.
- Calculated total revenue generated from pizza sales.
- Identified the highest-priced pizza.
- Found the most commonly ordered pizza size.
- Retrieved the top 5 most ordered pizza types with their quantities.

### 2. Intermediate Analysis
- Calculated the total quantity ordered for each pizza category using table joins.
- Analysed order distribution by hour of the day.
- Examined the category-wise distribution of pizzas.
- Calculated the average number of pizzas ordered per day.
- Identified the top 3 pizza types based on revenue.

### 3. Advanced Analysis
- Calculated the percentage contribution of each pizza type to total revenue.
- Analysed cumulative revenue over time.
- Identified the top 3 revenue-generating pizza types within each pizza category.

## SQL Concepts Used
- Aggregate functions: `SUM()`, `COUNT()`, `AVG()`
- Filtering: `WHERE`, `HAVING`
- Grouping and sorting: `GROUP BY`, `ORDER BY`
- Joins across four related tables
- Subqueries and Common Table Expressions (CTEs), where applicable
- Window functions for ranking and cumulative revenue, where applicable

## Key Learnings
- Improved understanding of SQL joins and relational databases.
- Practised analysing sales data using aggregate functions.
- Learned to identify popular products and revenue-generating categories.
- Used ranking and cumulative calculations to examine sales performance over time.

## Conclusion
This project demonstrates the use of SQL to transform raw pizza sales data into meaningful business insights. It strengthened my ability to write analytical queries and understand sales trends, product popularity, and revenue contributions.
